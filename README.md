# Snowdropy ❄
Snow drop animation overlay for Android. **Powered by Rio X**

## APK build (GitHub)
1. Create a new GitHub repo and push all these files.
2. Open the **Actions** tab -> "Build Snowdropy APK" (runs on every push, or press "Run workflow").
3. When it finishes, open the run and download the **Snowdropy-APK** artifact.
4. Unzip it, install `app-debug.apk` on your phone (allow install from unknown sources).

## Use
Open the app -> Start Snow -> allow "Display over other apps" -> press Start Snow again.
